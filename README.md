# Church Sound Guide

교회 음향팀 교육 자료: 8개 대주제와 38개 소주제.

- `index.html`: 글과 구간별 영상
- `assets/`: 영상 38개와 포스터 38개
- `admin.html`: 로컬 콘텐츠 편집 화면

## 글 수정

이 폴더를 내려받고 Chrome 또는 Edge에서 admin.html을 엽니다.
콘텐츠 파일 연결 → 같은 폴더의 library-data.js 선택 → 편집 → 저장.
수정한 library-data.js를 GitHub 저장소에 올리면 Pages가 갱신됩니다.
온라인 홈페이지에서 저장해도 서버의 파일이 자동으로 바뀌지는 않습니다.

## 게시

GitHub Pages: main 브랜치의 최상위 폴더를 게시합니다.
.nojekyll 파일로 정적 파일을 그대로 제공합니다.
이 사이트에는 로그인 기능이 없으며 홈페이지와 영상은 공개됩니다.
